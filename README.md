## Features

-   Industrial HMI/SCADA-style components
-   User-configurable scales, ticks, units, and zones
-   Analog gauges, sliders, rotary knobs, and LED-style indicators

## Installation

``` bash
pip install industrial-instruments
```

## Components

-   Analog120
-   Analog180
-   Analog270
-   RotaryKnob
-   AnalogSlider
-   VerticalMeter
-   LEDSlider
